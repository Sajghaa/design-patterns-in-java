# Design Patterns in Java

This repository is a deliberate study of software design patterns through practice rather than memorization.

For every pattern, I document:

- The problem
- The naive implementation
- why it fails
- The design pattern solution
- Advantages and trade-offs
- Real-world use cases 
- Exercises
- Personal Reflections

## Goal

Understand *why* design pattern exist-not just how to implement them.

Every pattern is learned by first experiencing the problem it was designed to solve.
